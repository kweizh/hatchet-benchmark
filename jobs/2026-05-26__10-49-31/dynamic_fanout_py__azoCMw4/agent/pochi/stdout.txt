## How it works

**`square_item` (child workflow)**
- Input: `SquareItemInput(item: int)`
- Single task `square_item` returns `{"square": item * item}`

**`process_batch` (parent workflow)**
- Input: `ProcessBatchInput(items: list[int])`
- Single task `process_batch` builds `N` bulk-run items (one per element) via `square_item.create_bulk_run_item(...)` and fans them out with `await square_item.aio_run_many(bulk_items, wait_for_result=True)`.
- Results arrive back in the same order as the input list; the task aggregates them into `{"squares": [...]}`.
